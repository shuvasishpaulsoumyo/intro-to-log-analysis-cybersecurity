# TryHackMe: Intro to Log Analysis

## Project Overview

This project demonstrates my practical learning in log analysis using the TryHackMe **Intro to Log Analysis** room.

The objective was to understand how web server logs record activity and how log information can support cybersecurity monitoring and incident investigation.

## Objectives

- Understand the basics of log analysis.
- Explore a Linux-based AttackBox environment.
- Locate and view an `access.log` file.
- Examine HTTP requests and response status codes.
- Understand how log analysis supports security operations and incident response.

## Tools and Environment

- **Platform:** TryHackMe
- **Room:** Intro to Log Analysis
- **Environment:** TryHackMe AttackBox
- **Command used:** `cat access.log`
- **Log file:** `access.log`

## Practical Work

I connected to the TryHackMe AttackBox and navigated to the directory containing the access log file. I used the Linux terminal to display the log entries and examine the recorded HTTP requests.

The entries included client IP addresses, timestamps, HTTP methods, requested resources, status codes, and user-agent information.

I observed HTTP methods such as GET, POST, and PUT, along with status codes including 200, 404, and 500.

## Key Learning Outcomes

- Learned how to locate and view a log file in a Linux environment.
- Improved my understanding of web server access logs.
- Learned the meaning of common HTTP response status codes.
- Understood why security analysts need to interpret log evidence carefully.
- Connected practical log analysis with security monitoring and incident response.
